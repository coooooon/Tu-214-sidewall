# Оконные узлы двойной стеновой панели Ту-214 — доработка v5

К предоставленной панели добавлены две формованные оконные чашки, две цилиндрические пластиковые шторки, две низкие ручки и четыре скрытые направляющие. Основная сборка показывает поднятые шторки. Сохранены отдельные сборки с полузакрытыми и закрытыми шторками.

Цилиндрические поверхности шторок сохранены аналитическими; чашки содержат NURBS-поверхности. Треугольники используются при подготовке изображений.

Панель импортирована из `Tu214_double_sidewall_v5.stp`, без перестроения или правок. Копия исходного файла имеет SHA-256:

```text

```

При экспорте сборок сохранены 32 754 исходные STEP-записи геометрии и её контекста, включая исходный допуск 0,005 мм; изменены только номера сущностей, необходимые для включения в сборку. Независимый рекурсивный хеш определения панели совпадает во всех трёх сборках. Объём панели после повторного импорта равен исходному: **4 129 744,493924135 мм³**, разница 0 мм³.

## Контуры и чашка

Контур **A** взят из существующего оконного проёма. На дне выемки исходной панели он имеет примерно 336 × 453,85 мм в развёртке, на R1735. В панели уже есть радиусный заворот R18; он заканчивается контуром **A0** шириной 299,99 мм и высотой 422,55 мм на R1753. Новая чашка присоединяется к A0 с учётом фактической нормали исходной поверхности. Так сохраняется весь существующий заворот, без наложения второго тела на него.

Дальний световой контур **B** построен отдельно. У него восемь согласованных дуговых участков: верхняя и нижняя дуги, две боковые дуги, четыре угловых скругления. Между участками введены короткие переходы с непрерывностью кривизны G2. Углы B заметно более округлые. Максимальное отличие B от наилучшей масштабированной копии A0 составляет 15,38 мм. Верхняя и нижняя стороны B слабо выгнуты; они отличаются от прямых сторон большой рельефной выемки панели, которую эта доработка сохраняет.

Чашка построена из пространственных поверхностей пятой степени по глубине, с шестью рядами контрольных точек и заданными касательными на обоих концах. Соответствие контуров по полярной фазе предотвращает перекручивание. Касательная в начале учитывает существующую поверхность панели, в конце направлена радиально. Сшитая чашка является одним замкнутым телом. Толщина в проекции на нормаль по проверенной сетке составляет **1,914–3,000 мм**; номинальная ширина заднего торца 2,6 мм, переднего 3 мм.

## Зазор и движение

Задняя кромка чашки заканчивается на R1820. Принятая граница примыкания оконного блока находится на R1835. Между ними расположен **реальный радиальный коридор шириной 15 мм**, в котором перемещается шторка. Перед её поверхностью остаётся 7 мм, за ней — 6,2 мм. Оконный блок показан на сечении штриховой монтажной линией: его неизвестная заводская геометрия не добавлена в сборку.

Боковые направляющие имеют простой U-образный профиль, связанный с тем же цилиндром. Полотно входит под их полки с боковым зазором 2 мм до стенки; радиальные зазоры до передней и задней полок равны 3,7 и 3,9 мм. Это минимальная функциональная компоновка скрытых деталей, восстановленная по конструктивной логике. Крепёж, уплотнения и заводские профили направляющих не восстанавливались по невидимым участкам.

Шторка и ручка перемещаются совместно поворотом вокруг общей оси цилиндра, параллельной X, с координатами **Y = −1667,74165925 мм, Z = 354,489432844 мм**. Радиус и толщина пластины остаются постоянными.

| Положение | Ход по дуге от закрытого, мм | Поворот |
| --- | ---: | ---: |
| Закрыто | 0 | 0° |
| Полузакрыто | 174,5 | 5,472421° |
| Открыто, основная сборка | 349 | 10,944842° |

В открытом положении основная часть полотна скрыта над чашкой, в верхней части проёма видна низкая ручка. В закрытом положении пластина перекрывает весь контур B. Ручка остаётся связанной с передней стороной пластины при любом положении.

## Проверки и изображения

Все три STEP-сборки повторно импортированы и проверены: **11 корректных замкнутых тел в каждой**. Проверено совпадение исходной геометрии панели, положительная толщина чашек, отсутствие вырожденных участков и складок по пространственной параметризации, касательные сопряжения, концентричность и толщина шторок, перекрытие светового контура в закрытом положении.

Максимальный разрыв присоединительного контура составляет 0,0000044 мм. Измеренное расхождение нормалей на стыке с исходной панелью не превышает 0,021°, между сегментами чашки — 0,0023°. Проверки относятся к геометрии экспортированных STEP-файлов.

Пересечения с панелью и направляющими проверены булевыми операциями для полных объёмов движения. Для чашек использована дополнительная граница по выпуклой оболочке контрольных точек NURBS, действующая на всём ходе. Минимальный гарантированный радиальный зазор между чашкой и выступом ручки превышает 1,499 мм. ## Повторное построение

Проверено на Python 3.12, CadQuery 2.7.0 / OpenCascade 7.8.1.1.post1. Параметры находятся в [source/parameters.json](source/parameters.json); все размеры заданы в миллиметрах. Скрипты работают из любого текущего каталога, пути вычисляются относительно собственного расположения.

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python source/build.py
.venv/bin/python source/validate.py
.venv/bin/python source/validate.py --contacts 1
.venv/bin/python source/validate.py --contacts 2
.venv/bin/python source/render.py
.venv/bin/python source/analyse_base.py
.venv/bin/python source/reference_check.py
.venv/bin/python source/package.py
```

`build.py` создаёт отдельные детали и три положения сборки. `validate.py` проверяет экспортированные STEP, а режимы `--contacts` проверяют непрерывное движение; булевы проверки сложной исходной панели могут занять несколько минут. `render.py` строит пять обязательных видов и настоящее CAD-сечение. `reference_check.py` использует приложенную размеченную фотографию; для самого построения фотография не требуется. `package.py` проверяет актуальность отчётов относительно файлов и формирует архивы и SHA-256-манифест.

Чтобы изменить ход, задайте `shade_open_travel_mm`. Для промежуточного положения функция `move_on_cylinder` принимает длину хода по дуге и радиус шторки; используйте её одновременно для полотна и ручки. Изменение `cup_rear_radius_mm`, `shade_radius_offset_from_cup_mm`, размеров B или толщин требует повторного построения и всех геометрических проверок. Диапазоны направляющих пересчитываются из высоты и хода шторки. Контуры A и A0 всегда заново извлекаются из сохранённого оригинала.

Для воспроизведения используйте существующий клон репозитория. Развёртывание дополнительного Git worktree для этой задачи не требуется. Проверенная облачная среда использует виртуальное окружение `/workspace/.tu214-cad-venv`; воспроизводимые инструкции её установки и запуска сохранены в черновике конфигурации среды.
