# Оконный узел Ту-214 — исправленная версия 3

[Основная сборка](cad/assembly_open.step) · [Частично закрыто](cad/assembly_half.step) · [Закрыто](cad/assembly_closed.step).

Семь отдельных BRep-тел: исходная панель, две новые чашки, две цилиндрические шторки и две ручки. Отдельные STEP: [чашка 1](cad/cup_1.step), [чашка 2](cad/cup_2.step), [шторка 1](cad/shade_1_open.step), [шторка 2](cad/shade_2_open.step), [ручка](cad/handle.step). Остальные положения деталей находятся в `cad/`.

## Геометрия и размеры

Все размеры — мм. Чашка построена по фактическому проёму исходного STEP. Граница около 300 × 423 в развёртке плавно сужается к более округлому контуру 246 × 344 (суперэллипс, показатель 2,6). По глубине применены контролируемые квадратичные сечения со слабым единым C-образным изгибом; S-перегибов и декоративных валиков нет.

| Параметр | Значение |
| --- | ---: |
| Основная панель / обратная поверхность | R1705 / R1708 |
| Углублённая зона панели | R1735 / R1738 |
| Существующая кромка проёма | около R1753 |
| Передняя / задняя граница чашки | около R1769,5 / R1824,5 |
| Толщина стенки чашки по смещению контура | 3 |
| Шторка: две цилиндрические поверхности | R1761 / R1762,8 |
| Шторка: ширина × высота в развёртке | 322 × 432 |
| Ход / полхода по дуге | 380 / 190 |
| Ручка: ширина × глубина × высота | 100 × 40 × 25 |

Радиус шторки принят больше радиуса панели согласно уточнению пользователя. **Шторка находится между панелью и чашкой.** Коридор возле существующей кромки около 16,5 мм, близко к ориентировочным 15 мм задания. В поднятом положении пластина скрывается за панелью над окном. Движение — поворот вокруг исходной оси X (Y = −1667,74165925; Z = 354,489432844), с постоянными радиусом и толщиной.

Ручка имеет линзовидный фронт с двумя осями симметрии, клиновидный боковой профиль и слабовыпуклый контур спинки напротив заметно вогнутого захвата. Она закреплена у нижней кромки шторки. Небольшой интегральный монтажный участок 20 × 2 × 1,5 имеет цилиндрическую контактную поверхность R1761; он соприкасается с пластиной без объёмного пересечения. У тела захвата предусмотрен монтажный припуск 0,05.

## Допущения и воспроизведение

Световой контур, глубина чашки и скрытая компоновка оценены по референсам; это не заводские размеры. Геометрия остекления, оконного блока, крепежа и направляющих не предоставлена. Она не добавлялась в сборку. Задняя граница чашки задаёт принятое место примыкания блока; скрытое крепление требует уточнения перед изготовлением.

Python 3.12, CadQuery 2.7.0 / OpenCascade. Из корня репозитория:

```bash
python -m venv work/tu214-v3-venv
work/tu214-v3-venv/bin/python -m pip install -r corrected-window-v3/requirements.txt
work/tu214-v3-venv/bin/python corrected-window-v3/build.py
work/tu214-v3-venv/bin/python corrected-window-v3/validate.py
work/tu214-v3-venv/bin/python corrected-window-v3/render.py
```

Параметры: `parameters.json`. Повторно используются только разбор исходного проёма, построение аналитических цилиндров и сохранение STEP-записей из `../tu214-sidewall/source/`. Старые чашки, шторки и ручки не импортируются.
